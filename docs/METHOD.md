# 算法原理与样本如何改善规则

## 从输入到成图

1. 读取 RGB 和独立透明度，区分纸白背景、完整场景与透明立绘。仅当背景具备足够的中性参考时才考虑修正白平衡。透明像素和半透明边缘在输出时按原通道处理。
2. 提取线条与区域，根据颜色、邻接、明度和位置估计材质。建立轮廓、材质交界和同材质内线的层级，估计脸、眼和饰物保护区域。归类可能出错，因此保留调试图。
3. 分解底色、阴影、高光和墨线。以通道值 0 到 1 表示，底色乘以阴影得到漫反射色；在剩余亮度空间上叠加高光，最后按墨线透明度合成。这样可分别调整皮肤亮纹、折面与线重。
4. 衣褶沿主要方向寻找两侧边缘，逐渐收窄到两端；发束、袖口、皮带按各自材质调整。同材质内部受光线可以减轻，遮挡和轮廓需要维持可读性。亮纹规则只在几何关系、邻域肤色和明暗条件成立时介入，膝盖转面、投影和逆光边均作为复核对象。
5. 比较原图和临时合成：检查被削弱的小色块、细线、重复图案和金属弧边。对证据足够的像素恢复原分层内容。完整卡面与透明人物的图案检验条件不同。已审阅过的陌白原图按解码图像身份匹配其保护蒙版，其他图走自动判断。
6. 写最终图、分层和检查报告。复跑时以报告中的摘要匹配上一遍蒙版，避免把另一张图的保护范围用在本图。可选降噪保留来自原稿的几何分析，额外计算由独立的本地解释器完成。

## 本项目如何“训练”

开发过程中使用人类画师参考图、122 张卡面、局部网格观察和用户盲测来调整规则。训练对象是算法的判断条件和助手的执行流程。把一批图片放入目录不会触发参数更新，也不会改变基础语言模型权重。

一个实际例子是穿绳孔。原图暗孔和细亮边一起描述结构，初版弱化亮部时可能留下暗点却抹掉孔缘。定位原图坐标，在同一尺寸比较原图、第一遍、第二遍，核对孔缘、绳的连通和邻近布面。然后把眼睛反光作为干扰样本，看同一条保护规则是否误触。对浅色徽章，要数脸上的短笔触，仅核对外轮廓会漏掉退化。

## 添加一批新样本

| 步骤 | 应记录的证据 |
|---|---|
| 选样 | 记录来源与使用授权，覆盖浅色/暗色、写实反光/简洁色块、透明/有背景。一次拍摄的缩图和裁片归为同一组。 |
| 标注 | 对每处写原图像素坐标、材质、希望保留或减弱的笔触，以及原画中承担的作用。意见不一致时保留两种判断。 |
| 分组 | 将开发与验收按作品分开。先记验收标准，避免看到候选结果后才挑样或改标准。 |
| 改规则 | 每轮优先改一个能复现的失败。保留旧参数、候选参数、原图、两遍输出和前后同位置裁片。 |
| 回归 | 先查结构、透明度和既有保护案例，再查全身盲测。分别统计改善、持平、退化，并区分图数和裁片数。 |
| 合入 | 不同作品上能重复改善且没有相应代价时才设为默认。只对某张衣领有用的处理留作局部选项。 |

新的、有差异、有标签的样本更容易暴露盲区；只有经过更新和独立验证，它们才可能提高能力。大量重复样本或统一偏好也可能让规则偏向单一画风。

## 怎样检验弱模型能否接近较强模型

固定同一个内核版本和输入，分别给两个模型相同盲测集，记录模型版本、是否能直接读图、是否获得裁片和执行时间。人工预先标出“结构损失/合理保留/主观偏好”，逐项统计漏报、误报及正确回答“看不清”的比例。先测完全不带操作书，再测带操作书，两组都保留未见作品。内核输出一致仅证明工具调用可复现；识图能力要用这项独立实验测量。
