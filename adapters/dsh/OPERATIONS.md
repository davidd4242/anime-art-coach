# DSH 操作书：先运行，再识别，最后判断

使用者可以把这份文件交给 DeepSeek Harness 的模型。工具把相同输入按固定规则渲染；模型的任务是选择检查位置、阅读结果、准确表达不确定性。没有图像输入能力时，仍能完成文件、尺寸和参数核对。

## 初次使用者

1. 在项目根目录按 docs/USAGE.md 安装 Python 依赖。先在终端运行下面的示例，确认输出目录出现。
2. 在 DSH 的工作区打开项目，要求助手先读本文件。若用 CLI，先执行 `dsh --help`，确认是支持 headless profile 的 DeepSeek Harness。模型、账号和用量由使用者现有的 DSH 配置决定。
3. 运行一次默认处理。下例要求在同一张图上验证连续处理，原图 997 × 1578。坐标以左上角为原点，顺序是左、上、右、下，右和下不包含在选区内。

```sh
python adapters/dsh/run.py examples/momo.png runs/momo-review --passes 2 \
  --crop 595 1011 655 1049 --crop 592 402 647 462 --crop 370 350 437 425
```

4. 打开 runs/momo-review。grid.png 给出全身位置，evidence.json 列出每格边界、数值和裁片名。三个 crop 文件按写入顺序排列，每张从左到右是原图、第一遍、第二遍。
5. 需要调用已配置的模型时，可在项目根目录执行 `(cd runs/momo-review && sh ../../adapters/dsh/review.sh)`。这一步向 DSH 提交只读任务，是否能查看图像取决于当前 profile 的工具，可能产生供应商用量。只做本地处理可在第 4 步结束。若 dsh 命令提示缺运行时，可先直接在桌面 DSH 打开输出目录并输入下方任务，Python 入口可独立运行。如果现有启动器引用了缺失的 Node，而系统 Node 与已安装的 DSH 包可用，先用 node 运行该包的 lib/bin.js --help 检查，再把 DSH_CLI_JS 设为该 bin.js 的绝对路径；review.sh 会沿用此入口。

## 交给模型的逐步任务

**第一步：区分原稿与成品。** 询问或读取用户明确给出的文件角色。示例中 momo.png 和 starfish.png 是原稿，文件名带 delivered 的是用户指定的成品。比较图不可作为源图再处理。若身份不确定，先报告文件名和尺寸，等待确认。

**第二步：列出可数的检查项。** 例如“兔子脸上两笔粉线、两个耳内色块”“黑色交叉带中上下两处开口”。写明物件在哪一侧、颜色、数量及邻近物件。对画法给出具体标准，例如“前腿两条长亮纹能否收敛，同时膝盖转面仍可读”。每轮先选 2–4 项。

**第三步：选坐标。** 从 grid.png 定位到格子，再给原图像素框。若只有缩略图坐标，分别乘以原宽/预览宽及原高/预览高。不要把白底成品的坐标直接套给透明原图。不指定 --crop 时，脚本返回变化最大的三个有可见像素的格子；小图案很容易被平均数淹没，仍需主动框选。

**第四步：看完整性。** 核对 evidence.json 的 size、passes、alpha_equal。读取 pass-1/report.json 的 params 和 denoise；两遍时再确认第二遍报告里的 input 指向 pass-1/result.png。尺寸或透明度检查失败时脚本会停止，不能据此宣称成功。

**第五步：逐物比较。** 一次看一个裁片。先看原图中的开口、线头和数量，再在同位置找第一遍、第二遍的对应物。示例猫脸检查左右耳和脸内浅点；兔子检查两笔粉线是否还分开；交叉带先看孔，再看孔内的蓝色。孔内变亮与黑带断裂应分开记录。看到高光时先判定是否在眼睛、金属、皮肤或布料上，列出支持判断的邻近形状。看不清就标“待人工核对”。

**第六步：解释数字。** mean_abs_rgb 是可见像素在相同灰底上、原图到最后一遍的通道平均绝对变化，范围 0–255。变化为 0 仅表示在显示精度下相同。变化较大可能来自布面调整，也可能来自装饰损坏。坐标框能定位原因，分数本身不能选赢家。

**第七步：给简短结论。** 先陈述整图改动是否看得见，再列逐物证据。允许输出“持平”。如果只在第二遍发现断线，记录第一次出问题的遍数；如果只在特定原画成立，留为单图处理。保持日常参数，等用户明确要求再改内核。

可直接提交给弱模型的任务：

> 使用本地算法处理 examples/momo.png，输出新目录，核对两遍。先读操作书，报告原图尺寸。根据给定框检查猫脸、兔子粉线、黑色交叉带。每项输出“坐标 / 原图有什么 / 第一遍 / 第二遍 / 证据文件 / 是否需要人工确认”。无法查看裁片时只汇报数字和文件位置。最后写一句全身观感；没有看到全身图时注明未观察。

**出现分歧时。** 模型若说“高光太强”，要求指出哪一条、沿哪个方向、遮挡处是否还有阴影。当两个模型结论冲突，给人看同倍率盲测图，记录更偏好哪张或是否持平。工具能减少步骤遗漏，模型间效果是否接近按 docs/METHOD.md 的留出集方案评测。
